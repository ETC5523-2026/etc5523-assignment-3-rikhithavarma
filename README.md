
# Rikhitha Varma | Data Stories

## About This Project

This repository is my personal website, built using Quarto for ETC5523: Communicating with Data at Monash University.

The site presents a summary of my work and interests in data analytics, visualisation and data storytelling. It also has a research-based blog post that is adapted from my technical report for Assignment 2.

## Featured Blog Post

**The Hidden Danger of Hospital Infections: Why the Most Common Infections Are Not Always the Most Harmful**

This article explores the burden of healthcare-associated infections in Germany, drawing on research published by Zacher et al. (2019).

It compares the frequency of different infections with their estimated health impact, using a data visualisation and a summary table.

## Intended Audience

This blog is intended for university students and interested general readers who want to understand public health issues without requiring specialist medical or statistical knowledge.
